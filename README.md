Self made version of the game "2048". More about the game - https://en.wikipedia.org/wiki/2048_(video_game)
The initial version does not have a GUI and is played in console.
"wasd" is used for movement where 'w' is up, 's' is down, 'a' is left, 'd' is right. 'q' is used to quit the game.

Project goals:
1.Fix edge cases where possible movement does not happen
2.Make .exe version 
3.Make a GUI version
