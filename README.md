Java version of the game "2048". More about the game - https://en.wikipedia.org/wiki/2048_(video_game)
The initial version does not have a GUI and is played in console.
"wasd" is used for movement where 'w' is up, 's' is down, 'a' is left, 'd' is right. 'q' is used to quit the game.

Project goals:
1.Implement default rules where numbers slide as far as they can and not 1 tile per move
2.Fix edge cases where possible movement does not happen
3.Make a GUI version
4.Make .exe version 
5.(Bonus_1) make score version
6.(Bonus_2) make android version
